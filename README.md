# Animated Developer Portfolio

React + Vite + Tailwind CSS + Framer Motion.

## Run locally
1. Install Node.js 18+ from https://nodejs.org
2. In this folder run:
   npm install
   npm run dev
3. Open the URL shown (usually http://localhost:5173)

## Customise
Edit `src/data.js` for your name, skills, projects, experience, testimonials and links.
Colours live in `tailwind.config.js`.

## Deploy
npm run build   -> outputs `dist/`. Upload `dist/` to Netlify, Vercel or GitHub Pages.
